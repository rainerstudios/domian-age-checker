# Domain Age Checker - Homepage

This repository contains the homepage and privacy policy for the **Domain Age Checker** Chrome extension.

## 🌐 Live Website

The homepage provides information about the Chrome extension and serves as the privacy policy host for Chrome Web Store requirements.

## 📁 Files

- `index.html` - Main landing page showcasing the extension features
- `privacy-policy.html` - Privacy policy required for Chrome Web Store submission
- `README.md` - This file

## 🔗 Privacy Policy URL

For Chrome Web Store submission, use this privacy policy URL:
```
https://rainerstudios.github.io/domian-age-checker/privacy-policy.html
```

## 🚀 Chrome Extension

The actual Chrome extension is located in a separate repository. This homepage supports the extension publication process by providing:

- ✅ Privacy policy hosting
- 📱 Feature showcase
- 🖼️ Screenshots and demos
- 📞 Support information

## 📋 Chrome Web Store Requirements

This homepage addresses the Chrome Web Store requirements:

1. **Privacy Policy**: Hosted at `privacy-policy.html`
2. **Screenshots**: Placeholder sections for extension screenshots
3. **Clear description**: Feature explanations and use cases
4. **Contact information**: Support links and GitHub repository

## 🛠️ Local Development

To view locally:

1. Clone this repository
2. Open `index.html` in your browser
3. Or use a local server: `python -m http.server 8000`

## 📝 Notes

- The privacy policy clearly states that no personal data is collected
- The extension only uses minimal `activeTab` permission
- All domain queries are made directly to third-party APIs without storing data
